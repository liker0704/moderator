# TG-консоль модератора для Discord ↔ Telegram

Версия: 1.0
Дата: 16.11.2025

## Описание

Сервис предоставляет модератору единую консоль в Telegram (бот), куда поступают входящие сообщения из Discord и Telegram. Модератор может отвечать на сообщения через единый интерфейс с подтверждением отправки.

### Основные возможности

- Прием сообщений из Discord через прямое подключение пользовательского аккаунта к Gateway
- Прием личных сообщений из Telegram
- Единая консоль для ответов через Telegram-бот
- Карточки сообщений с метаданными и контекстом
- Обязательное подтверждение перед отправкой ответа
- Режим "Не беспокоить" (DND) с гибкими интервалами
- Поддержка изображений и скриншотов
- AI-генерация вариантов ответов (v0.2+)
- Хранение данных 90 дней

## Целевая аудитория

Система разработана для одного модератора (единственный пользователь).

## Технический стек

- Backend: Python/Node.js (определяется при реализации)
- База данных: PostgreSQL
- Интеграции: Discord Gateway (User Token), Telegram Bot API
- Деплой: Docker
- LLM: OpenAI API / Anthropic Claude (v0.2+)

## Быстрый старт

1. Настроить переменные окружения (см. [DEPLOYMENT.md](docs/DEPLOYMENT.md))
2. Запустить через Docker Compose
3. Настроить Discord подключение через команду /setup_discord
4. Настроить allowlist каналов через /allow_channel
5. Начать работу

## Важные замечания

⚠️ **ВНИМАНИЕ**: Проект использует прямое подключение пользовательского аккаунта к Discord Gateway, что нарушает Terms of Service Discord. Использование на свой риск.

- Формат ответов: только чистый текст (без Markdown)
- Хранение: 90 дней, без бэкапов (осознанное решение)
- Единственный пользователь: система не поддерживает несколько модераторов
